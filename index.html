Infrastructure-as-Code Deployment Pipeline

A Terraform and GitHub Actions pipeline that provisions AWS infrastructure and ships a containerized app to ECS Fargate across dev, staging and production.

  • Built reusable Terraform modules for AWS networking, ECS Fargate, security and monitoring across three environments.
  • Created a GitHub Actions pipeline that validates Terraform, runs tests, pushes Docker images to Amazon ECR and deploys to staging before production approval.
  • Authenticated GitHub Actions to AWS with OIDC and short-lived role credentials, so no long-lived access keys are stored.
  • Added deployment health checks with rollback: a failed release restores the previous ECS task definition.
  • The ECS service scales from 2 to 6 tasks on CPU load, and the same image that passed staging is promoted to production after manual approval.

A demonstrated project, not a running production service: I applied and tested the infrastructure, then destroyed it to avoid costs. The README documents the architecture, runbook, cost estimates and limitations such as HTTP-only load balancing.

Three-Tier DevSecOps MERN Stack on AWS EKS

The infrastructure and delivery workflow for a three-tier MERN application on Kubernetes, with security scanning built into the pipeline.

  • Provisioned the AWS EKS infrastructure with Terraform and built the delivery workflow with Jenkins, Amazon ECR, Kubernetes and ArgoCD.
  • Automated CI stages for code quality and security scanning with SonarQube and Trivy, then published frontend and backend images to ECR.
  • Configured ArgoCD to sync Kubernetes manifests from GitHub for GitOps-based deployment.
  • Ran 2 frontend and 3 backend replicas with health probes, and MongoDB persistence on a PVC backed by EBS.
  • Added Prometheus and Grafana monitoring, and documented troubleshooting, security findings and cloud cleanup.

The application source came from the institute’s starter repository; the infrastructure, pipelines, manifests and monitoring are my work. The Trivy scans found outdated base images and vulnerable dependencies, which I documented as findings to fix next.
